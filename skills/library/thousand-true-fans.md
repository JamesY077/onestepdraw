# 1000 个铁粉

## 何时使用

要做个人品牌、知识付费、创作者商业化，或流量很大但收入不稳时。

## 核心公式

> 1000 个愿意每年为你付 1000 元的铁粉 = 100 万 / 年。

重点不是 1000 这个数字，而是**直接关系**：你能不能被同一个人反复找到、反复服务、反复收费。

## 四层结构

1. **人群**：只选一个能被一句话描述的人群，写清他们的具体困境。
2. **内容**：持续回答同一类问题，形成可识别的主题；不追所有热点。
3. **社群**：给铁粉一个共同身份与固定场域（ newsletter、群、线下小聚）。
4. **产品**：从免费内容 → 低价工具 → 高价服务，逐级承接，不跳级。

## 工作步骤

1. 写下「我帮谁，解决什么问题，用什么方式」。
2. 列出 20 个该人群真实问过的问题，选 3 个作为内容支柱。
3. 设计一个 7 天内容节奏：3 条公共内容 + 1 次深度内容 + 1 次互动。
4. 设计一个最小付费产品（≤3 天可交付），先卖给 10 个人。
5. 建立直接联系渠道（邮件/社群），不把关系留在平台算法里。

## 输出格式

```text
目标人群：……
核心问题：……
内容支柱：1 / 2 / 3
7 天节奏：……
最小产品：价格 / 交付物 / 交付周期
首批 10 人从哪来：……
复购路径：免费 → 低价 → 高价
```

## 检查清单

- [ ] 人群具体到能说出他们昨天遇到的一个问题？
- [ ] 内容是否围绕同一主题累积，而不是每天换方向？
- [ ] 有没有不依赖平台推荐的直接联系渠道？
- [ ] 最小产品能在 3 天内交付且不砸口碑？
- [ ] 铁粉能被识别和感谢吗？
