# 爆款文案

## 何时使用

要写标题、短视频口播、商品卖点、详情页首屏、活动文案，或诊断「文案没人看完」时。

## 先定三件事

1. **给谁看**：具体到一个人群和处境，不写「所有人」。
2. **只讲一个卖点**：一句话说不出重点，就还没想清楚。
3. **看完做什么**：点击、下单、评论、收藏，只留一个动作。

## 四步写法

### 1. 钩子（前 3 秒 / 前 18 字）

四类可用钩子，一次只选一类：

- **结果前置**：先说用户能得到什么。
- **反差**：常识 vs 事实，制造认知缺口。
- **损失**：不做的代价，具体到钱、时间、机会。
- **具体数字**：用可验证的数字替代形容词。

### 2. 证据

- 一个真实场景 + 一个细节 + 一个可验证数字。
- 形容词不超过三个；每个形容词后面跟一个可看见的证据。
- 不编数据；没有数据就写过程和对比。

### 3. 价值

用 FAB 只走一条主链：功能（是什么）→ 作用（所以能怎样）→ 好处（对你意味着什么）。

### 4. 行动

- 一个动作，降低门槛（「先看 30 秒」比「立即购买」轻）。
- 给一个现在做的理由：限量、时限、下一步会发生什么。
- 不叠加多个 CTA。

## 输出格式

```text
标题（3 个，≤18 字）：
1. ……
2. ……
3. ……

正文：钩子 / 证据 / 价值 / 行动
15 秒口播版：……（约 45–55 字）
自检：主卖点 / 目标人群 / 行动指令 / 证据来源
```

## 检查清单

- [ ] 标题只承诺正文能兑现的事？
- [ ] 3 秒内知道「这跟我有什么关系」？
- [ ] 每条主张都有场景或数字支撑？
- [ ] 全文只有一个行动指令？
- [ ] 删掉所有「赋能、闭环、极致」这类空词后还成立？

## 反例

- ❌ 三个卖点并列，用户一个都记不住。
- ❌ 用「全网最低」但没有比较对象和来源。
- ❌ 结尾同时让人点赞、关注、下单、私信。
