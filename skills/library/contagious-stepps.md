# 疯传 STEPPS

## 何时使用

要做传播方案、话题设计、活动机制，或复盘「内容不错但没人转」时。

## 六个杠杆

1. **社交货币 Social Currency**：转发它能让用户显得更聪明、更内行、更有品味。给他一个「我早知道」的理由。
2. **诱因 Triggers**：把内容和用户每天都会遇到的东西绑定（天气、通勤、加班、点外卖），让线索随时唤醒记忆。
3. **情绪 Emotion**：优先高唤醒情绪——愤怒、敬畏、焦虑、兴奋；避免低唤醒的满足与悲伤。
4. **公共性 Public**：让使用和参与可见（可晒的成果、可见的标记、可模仿的动作）。
5. **实用价值 Practical Value**：给出能立刻用上的清单、模板、避坑点；信息要具体到可执行。
6. **故事 Stories**：把主张装进一个有角色、有冲突、有转折的故事；故事要能自然带出品牌或产品。

## 工作步骤

1. 用一句话写清「谁会把这条内容发给谁，为什么现在发」。
2. 给六个杠杆各打 0–2 分，标出最弱的两项。
3. 只补最弱的两个杠杆，不要六项平均用力。
4. 产出一个主方案 + 两个可替换的钩子。
5. 标出伦理与合规风险：不制造虚假紧迫、不消费灾难、不利用未成年人。

## 输出格式

```text
传播命题：……
目标动作：转发 / 模仿 / 讨论 / 购买（只选一个）
杠杆评分：社交货币 x / 诱因 x / 情绪 x / 公共性 x / 实用价值 x / 故事 x
补强方案：……
主钩子：……
可替换钩子：……
风险与边界：……
```

## 检查清单

- [ ] 用户转发时，能得到什么社交收益？
- [ ] 有没有一个每天都会出现的触发线索？
- [ ] 情绪是高唤醒的，而不是温吞的？
- [ ] 参与行为能被别人看见吗？
- [ ] 故事去掉品牌名还成立吗？成立说明品牌没长在故事里。
