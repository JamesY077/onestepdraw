# 影响力设计

## 何时使用

要写销售页、提案、招募文案、社群规则，或判断一个说服场景是否越界时。

## 七个机制

| 机制 | 可执行做法 | 边界 |
| --- | --- | --- |
| 互惠 | 先给一个真实有用的小东西，再提请求 | 不以赠品绑架选择 |
| 承诺一致 | 让用户先做一个小的公开选择，再延续到下一步 | 不伪造已做出的承诺 |
| 社会认同 | 展示同类人的真实选择与数量 | 数据必须真实、可追溯 |
| 喜好 | 找到真实共同点，先建立关系再谈事 | 不伪装身份与经历 |
| 权威 | 引用可核验的资质、来源、案例 | 不租借虚假头衔 |
| 稀缺 | 说明真实的限量、时限或机会成本 | 不制造虚假紧迫 |
| 联盟 | 用「我们」建立共同身份与共同目标 | 不制造对立与排外 |

## 工作步骤

1. 写清：对方现在相信什么、担心什么、下一步要做什么。
2. 从七个机制里选 **两个**，一个降低阻力，一个增加动力；不要全用。
3. 为每个机制写出具体证据与呈现位置（首屏、案例、CTA 前）。
4. 做一次「反操控检查」：如果对方知道你的手法，还会觉得合理吗？
5. 给出一个不依赖操控也能成立的替代方案。

## 输出格式

```text
目标对象与现状：……
期望动作：……
选用机制：A（降低阻力）+ B（增加动力）
证据与位置：……
话术示例：……
防御视角：用户如何识别这类手法？
合规边界：……
```

## 检查清单

- [ ] 所有数字、案例、名额都能被验证？
- [ ] 没有利用恐惧、羞耻或信息不对称？
- [ ] 用户拒绝后仍然容易退出？
- [ ] 去掉所有说服技巧，主张本身仍然成立？
