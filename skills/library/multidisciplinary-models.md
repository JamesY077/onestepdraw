# 多元思维模型

## 何时使用

面对高不确定性决策：要不要做、投入多少、何时退出，或需要复盘一次判断失误时。

## 六个常用模型

1. **能力圈**：只在自己能解释清楚边界的地方下重注；圈外要么学习，要么放弃。
2. **逆向思考**：先问「怎样一定会失败」，再逐条避免；比直接找成功路径更可靠。
3. **安全边际**：给预算、时间、流量留出 30% 缓冲；不把最乐观情况当基准。
4. **机会成本**：每个「做」都对应一个「不做」；把被放弃的最好选项写出来。
5. **复利**：优先能累积的能力、资产、信任；警惕一次性消耗。
6. **误判心理**：检查激励、从众、权威、损失厌恶、过度自信是否在替你做决定。

## 工作步骤

1. 写下决策问题与最晚决定时间。
2. 用六个模型各写一句话结论，标出冲突项。
3. 做一次「失败预演」：列出 5 个导致失败的原因与早期信号。
4. 给出下注比例与退出条件。
5. 记录本次判断的依据，便于之后校准。

## 输出格式

```text
决策问题：……
能力圈：在 / 不在
逆向清单：……（失败原因 + 早期信号）
安全边际：预算 / 时间 / 流量
机会成本：放弃的最好选项是……
复利判断：……
心理偏差自查：……
结论：做 / 不做 / 小规模试；退出条件：……
```

## 检查清单

- [ ] 是否因为「已经投入很多」而不肯退出？
- [ ] 最坏情况是否可承受？
- [ ] 决策依据是否写下来，能在三个月后复盘？
- [ ] 有没有把别人的成功结果误当成可复制的方法？
