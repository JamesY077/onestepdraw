风格：华尔街财经解读（W1 · 财经解读）

长什么样：深蓝织物舞台上放一个奶油金的巨大数字，镜头一直在缓慢往里推；新闻原文、当事人实拍、白底图表轮流上场，把"钱从哪儿来、到哪儿去"一笔一笔算给观众看。

适合：财经 / 商业 / 科技公司的选题——市值、融资、亏损、收购、财报、行业对比；也适合任何"一个数撑起一个论点"的科普与解说。

## 一句话原则

一个问题撑起全片：开头 5–7 秒抛出极值或反差（一个数、一笔账、一次对比），中间拆开算，结尾回答它，并压成一句判断。图形只演钱和关系；是谁、在哪、什么产品，一律交给真素材。

## 每一镜先写 says

每镜先写一句"这一镜让观众多懂了什么"，写不出来就删掉这一镜。先有 says，再从下面的组件里找意思对得上的画面，不按顺序套模板。每一镜接住上一镜的一样东西（同一个数、人、画框、原文），接不住要能说出为什么切。

## 视觉系统

- 底：深蓝织物的抽象舞台（`#0b1b33` 附近），四周压暗，全片叠一层很淡的颗粒。讲某一家时换成它的品牌色光：英伟达 `#3b7a1c`、OpenAI `#1c6b62`、算总账 / 亏损 `#6e1f26`。底是设计出来的世界，不假装真实场景。
- 大数字：奶油金渐变 `#fffef2 → #fff3b5 → #efdc7a`，1080p 下约 240–320px，窄体大写（Bebas Neue 一类）。位数写满（`$725,000,000,000`），不要出现 `$565,771,715,768` 这种假精确；示意的数在眉题里标"示意"。
- 图表：白底黑字，像一张纸放在深色舞台上；不用霓虹、外发光、渐变科技感。
- 字幕：白色一行，底部居中，整句替换、不逐字打出；1080p 下约 60px，柔和投影。中文黑体，夹的英文和数字用 Montserrat 斜体。底部 120px 的字幕带不放任何其他元素。
- 强调：全片只有一套强调色。正在讲的那一项给全色，其余压暗、去饱和或虚掉；一屏最多一组眉题（一行中文"谁 · 什么"，可带一行英文小字）。
- 真素材占四成以上：发布会、财报、官方广告、新闻原文截图、当事人实拍。素材要自己说清身份（脸、logo、标题），纯航拍、机柜这类规模镜头等主角立住后再放。

## 镜头与组件（按"这句话在说什么"选）

**数和钱**
- 一个决定性的数 → 巨大奶油金数字 + 眉题 +（可选）旁边一个小数对比。
- 一笔账 → 几个数用 `÷`、`×`、`≈` 连成一行，如 `$7250亿 ÷ 365天 ≈ $20亿/天`。
- 从多少变成多少 → 旧数缩小或划掉，新数长出来，倍数标在旁边。
- 两到四个数排开 → 数字 + 标签逐行出现；比高低 → 横向柱子，把差距那一段标出来。
- 占比 → 圆环画到那个百分比，只强调一个扇区；排行 → 横向条形从末位走到第一名。
- 逐项对比 → 左右两列，赢的一侧给颜色；按年变化 → 折线边讲边画，标出最高/最低/最后一点。

**关系和结构**
- 谁收购谁 → 小圆盘被大圆盘套住；几家公司并列 → 一排圆盘，念到谁亮谁。
- 钱怎么流 → 网络图 + 箭头；一件事分几步 → 流程节点依次点亮；三到六件事按时间排 → 时间线。
- 国家 / 城市之间 → 地图上打点连线。

**人和证据**
- 这个人 = 这个身份 / 这个数 → 当事人抠像站在画面中间，巨字分两组压在他头两侧，字在他的身后、底的前面，人还在动。
- 第一次出场 → 照片 + 名牌 + 两三件事；一句原话 → 引号 + 30 字以内短句 + 头像。
- 一段真画面 → 全屏实拍，镜头朝目标缓慢推近，角上最多钉一个圆盘徽章。
- 证据 → 先给整页认出处，再推近到那一句并刷黄，无关内容压淡；刷黄后清楚停 1 秒以上。自己排的页面不仿真实媒体，不写媒体名和标志。
- 片名 / 章节 / 金句 → 实拍压暗（亮度约 0.36）、去色一半、微虚，字是主角。
- 开头钩子 → 0.5 秒一张闪过本片后面会出现的画面，配一个关键词。

## 节奏与运动

- 0.5 秒内开口，第一镜不超过 8 秒，片名放在钩子之后。
- B-roll 每 2–3 秒换一个画面或落点；画面完全不动的时间控制在 20% 左右，不要定住超过 2 秒。
- 运动交给镜头，不交给元素：先快速推到位，再以约 3%/秒慢漂；往里推要多于往外拉。场景要有前后层（底纹、图形、人、前景粒子），镜头一动，远近动得不一样。
- 东西出现要朴素：淡入约 0.25 秒，或者切过来时已经在那儿。不做弹跳、回弹、打字机、扫光、整屏重排、带模糊砸进来。
- 快切只用于两处：开头关键词闪回；前景钉住一个东西、底下 0.4–0.6 秒换一段实拍。
- 转场能带过同一样东西就直切：下一镜开场就放上一镜的数、人、颜色。同一种接法不连着用两次。

## 竖屏 9:16

口播画面当底，大字和道具压在胸口位置；讲证据时人缩到角上的圆头像，画面换成图形或原文。图形放在一张有透视的斜台面上，卡片有厚度、柱子是长方体，被强调的那一项浮起来一层。颜色一个家族：一个主色（从口播画面里取）加三个低饱和伴色。

## 避免

- 不要 AI 氛围大片当底：熔炉、赌场、芯片神殿、霓虹城市；不要什么都在发光。生成的图只演拍不到的具体物件（一枚币、一座楼），同光同调色。
- 不要在清楚的实拍上贴电视台式下三分之一、名牌框、标签、来源小字。出处写进视频简介；画面上的出处只能是原文截图自带的。
- 不要满屏 3D 翻转、斜卡片墙、立体字。透视只留给"新闻摊在桌面上"和"上一镜倒成桌面"两种。
- 不要给每个元素加入场动画；不要每个数都滚动——只有"加起来、按年累计、一笔笔流进来"才滚，一条片最多两次，从第一笔开始，话说到那个数正好停。
- 不要照抄参考图里的文字、数字和公司名。用自己选题的真实数据，每个数、每个身份都能给出处。

## 交付格式

先给一张镜头表：每镜写 `says`（观众多懂了什么）、画面组件、时长、字幕原句；再展开成画面提示词。整片只回答开头提出的那一个问题，最后压成一句判断。
